FINAL auto scorecard website

Files included
- index.html
- styles.css
- app.js
- template.xlsx
- start_local_server.bat

Important
This website works best from GitHub Pages or a local server.
If you open index.html directly by double-clicking, some browsers block loading template.xlsx.

Recommended local use
1. Extract the ZIP
2. Double-click start_local_server.bat
3. Open http://localhost:8000

Workflow
1. Choose the scorecard image
2. Click Read Image
3. Review the auto-filled values
4. Click Generate Updated Excel
