ALDAR EXACT ORIGINAL EXCEL ROW UPDATER

This version was rebuilt to preserve the original Excel design exactly.

Important changes:
- The uploaded original workbook is used as the master file.
- The website does not rebuild the Excel workbook using SheetJS.
- It opens the .xlsx package directly and updates the next empty pre-formatted row in Weekly_Inspections.
- It keeps original fonts, font sizes, cell colors, borders, alignment, row heights, column widths, formulas, hidden/unhidden columns, charts and dashboards.
- It only changes cell values in the original row cells.
- Any value that cannot be read from the photo remains blank for manual entry.

How to use:
1. Open index.html.
2. Upload the original Excel file, or use the included original.xlsx.
3. Upload the photo. Review and fill any empty fields manually.
4. Click Create Updated Excel.
5. Open the downloaded file in Excel. Excel may recalculate formulas when opening.

Note: A browser cannot overwrite your local original file directly, so it downloads an updated copy.
