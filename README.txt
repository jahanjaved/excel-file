ALDAR DIRECT ORIGINAL EXCEL XML UPDATER

Why this version is different:
- It does not rebuild the workbook using SheetJS.
- It opens the original .xlsx as a ZIP/XML package.
- It updates only:
  1. xl/worksheets sheet for Weekly_Inspections
  2. xl/sharedStrings.xml for new text
- It fills the first empty pre-formatted data row already available in the original file.
- It preserves original sheets, charts, styles, formulas, relationships, dashboards, row heights and column widths.

Use:
1. Open index.html.
2. Upload your original Excel file.
3. Upload/read photo or fill website fields.
4. Click "Update Original Excel".
5. Download the updated original workbook.

Note:
Browsers cannot overwrite the original local file directly, so the updated file is downloaded.
