FINAL ALDAR PHOTO TO MASTER ROW SYSTEM

Main update:
- The system now inserts one new row into the uploaded / included master Excel file.
- The new row copies the same style, row height, cell design, number formats and structure from the previous filled record.
- It keeps the same sheet and same column positions.
- It fills only the mapped fields where data is available from the photo/form.
- Blank/unavailable fields remain blank for manual update.
- It does not create a separate plain entry-only sheet anymore unless you use the output row in the master workbook.

How to use:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge, or run start_local_server.bat.
3. Upload the scorecard photo.
4. Upload your latest master Excel file.
   - If you do not upload one, template.xlsx included in the ZIP will be used.
5. Review all extracted fields and scores.
6. Click: Insert New Row in Master Excel.
7. The downloaded Excel file will contain the existing master with one new styled row inserted at the bottom of the Weekly sheet.

Important:
- For best design preservation, always upload your latest original master Excel file.
- The system copies the style/size/design from the last filled row in the master sheet.
- It fills only fields that are detected or available in the form.
