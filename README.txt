ALDAR MANUAL KPI EXCEL UPDATER - NO PHOTO / NO OCR

What is fixed in this version:
1. Photo upload and scanning/OCR section is removed.
2. KPI values are entered manually only.
3. Copy Data for Excel button is fixed.
4. Copy button copies one full tab-separated row from column A to AX.
5. Paste directly into the first empty row of the Weekly_Inspections sheet, starting from column A.
6. Review + Update Excel button remains available for downloading an updated workbook.

Use:
- Open index.html or upload all files to GitHub Pages.
- Enter Reference Number last digits only, for example 290.
- Fill date, package, cluster and KPI scores manually.
- Click Copy Data for Excel.
- Open the main Excel file, click column A in the first empty row, press Ctrl + V.
