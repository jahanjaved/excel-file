ALDAR MANUAL KPI EXCEL UPDATER - NO PHOTO / NO OCR SCAN

What is changed in this version:
1. Photo upload and OCR scanning section removed.
2. KPI values are entered manually by the user.
3. The rest of the website logic remains the same.
4. Reference Number still accepts last digits only, for example 290.
5. The system automatically creates the full reference internally using:
   SIDPW-BW-KEO-ZZ-ZZ-XX-RP-HS-000290
6. Excel saves the FULL reference number in column A / Inspection_ID.
7. Review + Update Excel still creates the updated workbook.
8. Copy Data for Excel still copies the same A to AX tab-separated row pattern for manual paste.
9. The original workbook structure, formulas, formatting, charts and styles are preserved.

Use:
- Open index.html or upload all files to GitHub Pages.
- Enter Reference Number last digits only, for example 290.
- Enter the website data and KPI scores manually.
- Click Copy Data for Excel to paste into the main file, or Review + Update Excel to download an updated workbook.
