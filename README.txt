FINAL SAFE ENGINE - Aldar Weekly Inspection Photo to Excel

Files included:
- index.html
- styles.css
- app.js
- template.xlsx
- start_local_server.bat
- .nojekyll

What this version does:
- Uses the uploaded Excel file as template.xlsx.
- Keeps the same workbook, same sheet, same design, same existing data.
- Updates only the Weekly_Inspections sheet.
- Adds one new row after the last filled row.
- Copies template row formatting and formula pattern.
- Fills input columns from photo/OCR and reviewed extracted data.
- Does not create extra sheets or extra columns.

GitHub Pages:
1. Upload all files to the root of your GitHub repository.
2. Keep names exactly the same.
3. Enable GitHub Pages.
4. Open the site.
5. Upload the scorecard photo.
6. Review extracted values.
7. Click Generate Excel.

Local:
1. Extract ZIP.
2. Double-click start_local_server.bat.
3. Open http://localhost:8000
