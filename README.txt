FINAL ALDAR TEMPLATE UPDATE SYSTEM - NEW ROW ONLY

What this version does:
- It does NOT make a plain entry-only workbook.
- It updates the master template by inserting ONE new row at the bottom of the Weekly sheet.
- The new row copies the same design from the previous filled record:
  same font, same font size, same borders, same fills, same row height, same column widths, same formulas where applicable.
- Only mapped/available fields from the photo and website form are filled.
- Fields that are blank or not detected remain blank, except formula cells copied from the previous row.

How to use:
1. Extract the ZIP.
2. Open index.html, or run start_local_server.bat.
3. Upload the photo.
4. Upload your latest template/master Excel file.
   If you do not upload, the included template.xlsx will be used.
5. Review extracted data and manually correct any blank fields.
6. Click "Update Template + Download".
7. The downloaded Excel file is the updated template/master file with one new styled row added.

Important:
- Always upload your latest master file if you already have previous records.
- The system preserves workbook structure as much as possible in browser mode.
- It fills only the columns that match the existing master headers.
