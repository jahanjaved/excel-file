ALDAR ORIGINAL FILE UPDATE SYSTEM

This version is built for exactly this workflow:
- Keep the original Excel file pattern/design.
- Add only one new row in the original Weekly sheet.
- Copy the previous filled row design, font size, row height, borders, formats and formulas.
- Fill only the columns that have data from the website/photo.
- Leave empty/unavailable fields empty.
- Do not create a plain separate row file.

Important:
Browser websites cannot overwrite your local Excel file directly. The system reads the original file, updates it in memory, and downloads the updated original-style Excel file.

How to use:
1. Extract this ZIP.
2. Open index.html or run start_local_server.bat.
3. Upload your photo.
4. Upload your latest original Excel file.
5. Review data.
6. Click Update Original File.
7. Download the updated original Excel file with one new row added.
