ALDAR MANUAL KPI EXCEL UPDATER - PHOTO SCANNING REMOVED

What is changed in this version:
1. Photo upload and OCR/scanning option removed completely from the website screen.
2. KPI values are entered manually by the user.
3. Website still shows ONLY one reference field: Reference Number.
4. You enter the last digits only, for example 290.
5. The system automatically creates the full reference internally using:
   SIDPW-BW-KEO-ZZ-ZZ-XX-RP-HS-000290
6. Excel saves the FULL reference number in column A / Inspection_ID.
7. The original workbook structure, formulas, formatting, charts and styles are preserved when using Update Excel.
8. Copy Data for Excel copies the website data as tab-separated Excel row data from column A to AX.

Use:
- Open index.html or upload all files to GitHub Pages.
- Enter Reference Number, date, package, cluster and KPI scores manually.
- Review the auto text.
- Click Update Excel to download the updated workbook, OR click Copy Data for Excel and paste directly into the first empty row of the main Excel sheet.
