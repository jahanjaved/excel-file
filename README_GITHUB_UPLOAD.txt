ALDAR GITHUB AI VISION OCR - FINAL STATIC WEBSITE

This folder is made for GitHub Pages upload.

How it works:
1. Upload all files in this folder to your GitHub repository.
2. Open your GitHub Pages website.
3. Paste your OpenAI API key in the OpenAI API Key box.
4. Upload your handwritten KPI photo.
5. The website calls OpenAI Vision directly and fills the fields.
6. Review the fields and click Review + Update Excel.

Important:
- GitHub Pages is a static website. It cannot hide an API key on a server.
- This package does NOT hard-code your key inside the files.
- The key is only stored in your own browser local storage after you paste it.
- Do not share your API key and do not publish a file containing your key.
- If your company requires secure key handling, use the server version instead.

Files to upload to GitHub Pages:
- index.html
- app.js
- styles.css
- aldar.png
- original.xlsx

You do not need server.js, package.json, .env, or BAT files for this GitHub static version.
